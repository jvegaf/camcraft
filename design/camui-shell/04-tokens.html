Campilot — visual tokens

The reference app's charm is not decoration: it is a graphite canvas, one line weight, and two signals that never compete. Geometry you touch is cyan; material the tool will remove is amber. Everything else is neutral. Values below are the only ones the shell is allowed to use.

02 The two signals

Selection

Anything the pointer owns: selection, hover, focus ring, active tool, active tab.

--sel #6fd3e8 · --sel-soft 13%

Cut

What the tool does to material: toolpath preview, depth, feeds, and the one primary action.

--cut #f5a623 · --cut-soft 13%

Pass

Verification only: simulation clean, no gouge, no uncut, file written.

--ok #5ec27f

Watch

Something is legal but unwise: tool too wide, toolpath deeper than the stock.

--warn #f0b429

Stop

Gouge, crash, open vector where a closed one is required. Always paired with words.

--danger #f2635f

Rule: a colour never carries a message alone. Cut and Selection differ in hue and in weight (toolpaths are 2 px dashed, geometry is 1.4 px solid), so the screen survives a monochrome screenshot and a colour-blind operator.

Numbers are furniture

Every value that a machinist may compare sits in a column, so it gets tabular figures and a unit column.

stepdown 2.000 mm
feed 1200.0 mm/min

Never mix units in one column, and never hide the unit: the status bar says mm and no field repeats it.

06 What this rules out

Banished

Each one is a thing the current shell does, or would drift into.

· A second accent hue “just for this panel”
· Filled or gradient icon sets beside the line set
· Widgets of more than three heights in one column
· Shadows on docked surfaces — hierarchy is a hairline
· Colour-only meaning, at any level
· A raw DragValue with no unit and no label

Mandatory

The parts a plain egui `ui.label` layout cannot express today.

· Every interactive element has a focus ring and a text alternative
· Every icon-only control carries a tooltip with its name and shortcut
· Numeric fields align right on tabular figures, unit in a fixed column
· Destructive or expensive actions are never the primary colour
· Motion respects prefers-reduced-motion and never exceeds 140 ms
