- **S4** — Rule 1 of the architecture, in force since M0 (verbatim, `odd/roadmap/index.md` §3): "**`cam-cli` is the contract.** Any behaviour that cannot be produced headless through the CLI is not considered testable, and therefore not done."

- **S6** — Verification rule 5 (verbatim, `odd/roadmap/index.md` §5): "**Simulation as oracle** — for each strategy, a test asserts the simulated removed volume matches the analytic expectation within tolerance; a too-shallow pocket fails the test, not a screenshot." Applies to M8 with a cross-section footprint instead of a single depth.
- **S7** — Assumption (not a user order, carried from D-M4-8 / M7 S15): M8 is authored through `cam-cli toolpath`; no toolpath form in the window. Precedent string (`crates/cam-ui/src/strategy.rs:104`): "This shell drafts a profile and a pocket; the rest are authored with `cam-cli toolpath`". If the owner orders a shell form, S7 is rewritten and a task is added; it is not silently absorbed.
